# 変更要望 影響分析レポート(Change Impact Analysis)

## 1. 変更要望の概要
- 要望元：経営層
- 要望内容：売上ダッシュボード機能の追加

## 2. 要件定義書への影響箇所
| 章 | 修正内容 |
|---|---|
| 2.1 システム境界図 | 会計システム連携を×→●に変更 |
| 2.2 機能スコープ | S-10 レポート機能をIn Scopeに変更 |
| 2.3 業務スコープ | 経営層向けレポーティング業務をInに移動 |
| 2.4 利用者スコープ | 経営層3名をInに、役割定義を追加 |
| 2.5 データスコープ | 売上データ（外部連携）を追加 |
| 2.6 Phase 2候補 | ダッシュボード項目を削除 |
| 2.7 完全に対象外 | 会計システム連携を削除 |
| 第5章 非機能要件 | モバイル対応、セキュリティ要件を見直し |

## 3. QCDインパクト試算
| 軸 | 影響 | 試算 |
|---|---|---|
| Quality | 中（外部システム連携でテスト工数増） | テスト工数 +30% |
| Cost | 大（会計システム連携の開発が必要） | 追加開発費 +200万円 |
| Delivery | 大（連携設計・テストで） | 納期 +1.5ヶ月 |

## 4. 顧客への提案オプション
- **オプションA**：全部受け入れ → 納期+1.5ヶ月、費用+200万円
- **オプションB**：Phase 2に回す → 当初計画どおり、ダッシュボードは半年後
- **オプションC**：他機能を削って吸収 → タグ管理を削除して工数捻出
